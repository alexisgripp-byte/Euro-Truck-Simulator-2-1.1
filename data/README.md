# Data sources

This folder stores all data used for building the map.

## Suggested subfolders

```text
data/
  osm/
  elevation/
  reference/
  generated/
```

## Purpose

- `osm/`: OSM road and feature data
- `elevation/`: terrain height and contour data
- `reference/`: textures, sample maps, and material examples
- `generated/`: outputs generated by scripts and conversion tools

## Important notes

- Keep raw source data separate from generated results
- Preserve source files for rebuilds and debugging
- Keep a record of the dataset version used for each tile or generation pass
